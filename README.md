# Bayora Shield

Bayora Shield is an isolated AI security testing platform for adversarial
evaluation, controlled model access, and tamper-evident audit trails.

## Project Goals

- Isolate Red Team, Blue Team, and Model environments.
- Control model access through an AI gateway.
- Detect selected adversarial prompt patterns.
- Maintain a verifiable audit trail.
- Validate security boundaries through automated tests.

## Project Status

Development in progress.

## Technology Stack

- Python
- FastAPI
- Docker
- PostgreSQL
- SHA-256 audit hash chain
- pytest

## Security Notice

Bayora Shield is a research and hackathon prototype.
It is not a production security platform.
